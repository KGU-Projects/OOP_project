# 오디오 리소스

이 디렉터리에 Java `javax.sound.sampled`가 재생 가능한 WAV 파일을 추가합니다.

권장 파일명:
- `bgm-start.wav`
- `bgm-game.wav`
- `bgm-quiz.wav`
- `sfx-button.wav`
- `sfx-correct.wav`
- `sfx-wrong.wav`
- `sfx-attack.wav`
- `sfx-hit.wav`
- `sfx-victory.wav`
- `sfx-defeat.wav`
- `sfx-chest.wav`

파일이 없으면 오디오 매니저는 조용히 넘어가며 게임 실행을 막지 않습니다.
