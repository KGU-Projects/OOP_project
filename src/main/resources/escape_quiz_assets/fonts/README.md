# 폰트 (퀴즈 전투 화면)

모두 SIL Open Font License 1.1 (OFL) 아래 배포되며, 프로젝트에 포함·재배포할 수 있습니다. 글꼴 파일을 수정하지 않고 그대로 넣었습니다.
라이선스 전문은 같은 폴더의 `OFL-*.txt`에 있습니다.

| 파일 | 용도 | 출처 |
|---|---|---|
| `Pretendard-Regular.otf`, `Pretendard-Bold.otf` | 문제·보기·해설·입력창(Regular), 버튼·팝업 문구·정답/오답 제목(Bold) (Pretendard v1.3.9, 한글 전체 글리프) | https://github.com/orioncactus/pretendard (Kil Hyung-jin) |

폰트 파일이 없거나 읽지 못하면 `game.ui.GameFonts`가 시스템 글꼴(맑은 고딕 등)로 대체합니다.

## 손글씨 글꼴 (UI 표시 문구 전용)

| 파일 | 용도 | 출처 |
|---|---|---|
| `Gaegu-Bold.ttf` | 닉네임·몬스터 이름·HP·STAGE·TIME·ESC·PAUSED 같은 짧은 표시 문구 (Gaegu Bold, 한글·영문·숫자). 문제·보기·버튼·해설에는 쓰지 않음. `OFL-Gaegu.txt` 참고 | https://github.com/google/fonts/tree/main/ofl/gaegu (The Gaegu Project Authors) |
